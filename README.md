# fareskhanchouch.com

Personal site of Fares Khanchouch, Forward Deployed Engineer (integrations and
LLM agent tooling). Next.js 15 (App Router, fully static), TypeScript,
Tailwind CSS 4. Hosted on Vercel.

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build (also type-checks and lints)
npm run start    # serve the production build
```

## Editing content

All text lives in **`src/data/index.ts`**; components only read from it.
Rules for what goes there are in `docs/PLAN_2026-10.md`: every fact must
match the résumé, no job-search signals (availability, relocation), and no
client names or client-internal figures on the public page.

| What | Where |
|---|---|
| Name, headline, intro, photo | `hero`, `about` in `src/data/index.ts` |
| Current role and past roles | `now`, `before` |
| Project cards (+ the steps of each flow diagram) | `projects` |
| Write-up article | `src/app/writing/grounded-resume-generator/page.tsx` |
| Résumé PDF | `public/resume.pdf` (generated by the job-search MCP; payload in that repo at `samples/website/public_resume.payload.json`) |
| Portrait | `public/portrait.jpg` (960×1440, no camera metadata) |

## Structure

```
src/app/
  layout.tsx            metadata, JSON-LD Person, fonts, skip link
  page.tsx              Hero, Work, Projects, About, Contact
  writing/...           the write-up page
  not-found.tsx, error.tsx, global-error.tsx
  robots.ts, sitemap.ts, manifest.ts, opengraph-image.tsx, icon.svg
src/components/         one file per section + Reveal, FlowDiagram
src/data/index.ts       all content
next.config.ts          security headers (CSP etc.)
```

Motion is CSS only (`src/app/globals.css`): content is always rendered
visible, only below-the-fold blocks fade in on scroll, and everything is
static when the visitor prefers reduced motion.

## Contact form

EmailJS from the browser (`emailjs` in `src/data/index.ts`; the public key is
public by design). The form has a honeypot, validation, length limits and a
30-second client-side rate limit. In the EmailJS dashboard, restrict allowed
origins to `fareskhanchouch.com` and enable reCAPTCHA if spam appears. The
template receives `name`, `email`, `subject`, `message`.

## Security and SEO checklist

- Security headers: `next.config.ts` (CSP allows only this origin plus
  `api.emailjs.com`; framing denied).
- No secrets in the repo; `.gitignore` blocks keys (`gitkey*`, `id_*`, `*.key`).
- `npm audit` should report 0 vulnerabilities; keep `next` patched.
- Sitemap and robots are generated; submit `https://fareskhanchouch.com/sitemap.xml`
  in Google Search Console once the domain is verified.
