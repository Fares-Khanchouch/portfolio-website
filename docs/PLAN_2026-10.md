# Site rebuild plan (2026-09-29, autonomous overnight run)

Source of truth for content: job-search-mcp/samples/website/WEBSITE_BRIEF.md
(facts from the owner's fact vault). This replaces REDESIGN.md (an older,
unapproved plan built around the "Infrastructure & Automation Engineer"
positioning, which the owner has moved away from).

## Decisions
- Positioning: Forward Deployed Engineer · Integrations & LLM Agent Tooling.
- Public page = no job-search signals (no "open to opportunities", no
  relocation, no availability) and no client names or client-internal figures
  ("banks in Qatar and Saudi Arabia", not CBQ / Saudi EXIM Bank / Doha Bank).
- Design (UI UX Pro Max: Minimalism & Swiss Style, dark; single accent):
  keep the navy + steel-blue system and Geist; fewer words, one explanatory
  animated flow diagram per project; 200-250 ms hovers, short fade-rise
  reveals that start VISIBLE when motion is reduced; nothing hidden from
  crawlers; contrast >= 4.5:1; visible focus; no emoji; 375/768/1024/1440.
- Stack unchanged: Next.js 15 (patched), TypeScript, Tailwind 4, Framer Motion.

## Steps (each its own commit, screenshots after each)
1. Security: remove committed SSH key + junk (done), patch deps (done).
2. Content: single data module (src/data/index.ts), all text from the brief.
3. Sections: Hero, Intro (bio, education, languages, skills), Experience
   (Now + Before), Projects (3 cards + flow diagrams), Contact, Footer.
4. Write-up page: /writing/grounded-resume-generator.
5. Platform: security headers + CSP (next.config), custom 404 / error /
   global-error, robots.ts, sitemap.ts, manifest.ts, OG image, canonical +
   metadataBase on fareskhanchouch.com, JSON-LD Person, contact-form honeypot
   and validation, no console noise.
6. Public résumé PDF (neutral client wording) at /resume.pdf.
7. Audit: build, lint, typecheck, npm audit, screenshots at 375/1440 and
   reduced motion, console errors, contrast check; PR for the owner.
